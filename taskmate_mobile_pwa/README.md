# 과제메이트

카카오톡 대화 TXT 파일을 분석해 조별과제 기여도를 참고 점수로 보여주고, D-DAY 일정을 관리하는 웹앱 프로토타입입니다.

## 실행 방법

1. `index.html`을 브라우저에서 엽니다.
2. 카카오톡 채팅방에서 `대화 내용 내보내기`로 TXT 파일을 저장합니다.
3. 앱에서 `카톡 TXT 불러오기`를 눌러 파일을 업로드합니다.
4. 기여도 표와 일정 후보를 확인하고, 필요한 일정은 D-DAY Planner에 직접 등록합니다.

## 기여도 계산 방식

- 메시지 수: 30%
- 글자 수: 25%
- 과제 관련 키워드: 18%
- 자료/링크 공유: 12%
- 활동일 수: 10%
- 긴 메시지 수: 5%

계산값은 절대 평가가 아니라 참고용입니다. 발표, 리더십, 오프라인 회의 참여는 별도로 반영해야 합니다.

## 개인정보

모든 분석은 브라우저에서만 실행됩니다. 서버 업로드 기능은 없습니다.
